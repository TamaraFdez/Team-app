# 🦸 Superhero Dispatch

Aplicación web para reclutar superhéroes y supervillanos, formar equipos y enviarlos a misiones. El reclutamiento se inspira en la mecánica de Tinder, mientras que la gestión de personajes y misiones toma referencias de _Dispatch_ y _Reigns_.
